# Contributing to numinia-fleet

**Contributions are closed to outsiders for now.** The [CLA](CLA.md) is a draft pending legal
review and is not yet offered to outside contributors. Until it is final, this repository accepts
changes only from Numen Games S.L. and its agents. If you are not one of them, you are welcome to
read, fork and use the code under `AGPL-3.0-only`, but a pull request from you cannot be merged yet.

For those who can contribute:

1. Read [AGENTS.md](AGENTS.md) first; it holds the rules for this repository.
2. Branch from `main` and open a pull request. Title, commits and comments in English.
3. Sign off every commit (`git commit -s`): it is the Developer Certificate of Origin.
4. Add your row to [CLA-SIGNATORIES.md](CLA-SIGNATORIES.md) in your first pull request
   (see [CLA.md](CLA.md) §5).
5. Run `reuse lint`; every new file states its licence in its first lines (STD-010).
6. Pablo (@PabloFMM) reviews and merges. Nobody merges their own pull request.

Never put an IP address, a key, an admin code or a client name in this repository.
